# tokengate-demo

Interactive demonstration project showcasing `tokengate` in action.

## Scenarios Demonstrated

1. **Standard Task Execution**: Seamless token counting and real-time dollar tracking across requests.
2. **Infinite Recursion Interception**: Trapping runaway nested agent reasoning loops before wasting credits.
3. **Budget Breaker Enforcement**: Instantly opening the circuit breaker when token or cost limits are hit.

## Running the Demo

```bash
node demo.js
```
